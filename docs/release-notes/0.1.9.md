# Purge 0.1.9 (alpha)

Alpha. Search, uninstalling several programs in a row, deleting from quarantine for good, and many fixes from a
full pass over the app.

## Changes since 0.1.2
- Programs: a search box (Ctrl+F; Esc clears it). Ticking several programs and choosing Uninstall now
  uninstalls them one after another ("Next: … (2 of 3)"), each with its own prompts and leftover check. Ticks are
  kept across tabs, filters and search; "No programs match" when nothing fits.
- Programs: a program Purge uninstalled leaves the list straight away and is no longer shown later as "Removed
  outside Purge". After "Check for leftovers" finishes, that program leaves the group; "Dismiss" removes it
  without checking.
- Quarantine: "Delete now…" for a whole cleanup can also delete its registry backups, if you tick "Also delete
  its registry backups (its registry changes can then no longer be undone)". Purge asks for them in a security
  prompt of their own.
- Quarantine: once a cleanup's files are deleted and only registry backups are left, it says "Registry undo
  only" and offers "Undo registry changes…" instead of promising the files back.
- Leftovers: "Delete instead of keeping in quarantine". Purge still moves the items to quarantine first, then
  asks in a second security prompt whether to delete them for good. If you cancel it, they stay in quarantine.
- Leftovers: registry entries are described in words ("Starts with Windows: Discord", "Your account › Startup
  apps"); the exact path is on hover and in the details pane.
- Leftovers: "Put back all" right after a move works again: Purge restarts its administrator part (one UAC
  prompt) instead of saying it cannot tell what was put back.
- Uninstall: a declined administrator prompt shows as "Not started" with "Try again", not as a failure. The step
  names are visible again.
- Settings shows only what works (theme, quarantine retention, about); placeholder options are hidden. About
  shows the real versions.
- Fixes for a crash seen while moving through the Programs page with the keyboard, for screen-reader names,
  narrow windows (minimum size 760 × 520), light theme and wording ("Quarantine", "Put back" everywhere).

## Known limits
- Alpha: everything Purge removes goes to quarantine first and can be put back from History & undo or
  Quarantine, until its retention ends or you delete it.
- No going back to 0.1.2 or older once registry backups were deleted early: an older Purge reads that cleanup's
  record as damaged and then refuses every new cleanup ("store integrity") until 0.1.9 or newer is installed
  again. Nothing is lost by this; installing the newer version again makes everything work as before.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
