# Purge 0.2.0-alpha.4 (pre-release)

Fourth pre-release of Purge's new window. The engine, the administrator part (broker) and the safety
rules are the same as in 0.1.9.

## What's new since alpha.3
- **Purge no longer keeps a CPU core busy while it sits idle.** In alpha.3 the window kept waking itself
  on every turn; now it sleeps until there is something to do.
- **The window remembers where you left it**: its position, size and whether it was maximized. On first
  launch it opens centred, a little larger than before. If its monitor is gone, it opens on the
  nearest one, kept inside the screen.
- **Whole-window Mica and Acrylic (trial).** Settings → Appearance → "Backdrop covers" can now be the whole
  window instead of only the title row and the rail. "Backdrop strength" (0–100 %, default 50 %) sets how
  much of the backdrop shows through. Purge caps it where text would stop being easy to read. Acrylic is
  where the slider matters most; Mica only tints. If you used Mica or Acrylic in alpha.3, the default
  50 % is subtler than before, and in dark mode Mica shows less of the wallpaper than it did.
- **No flash of the full list at launch.** The Programs page used to show every entry, components and
  unnamed ones included, for a moment before settling on the Apps tab. The first list you see is now
  the sorted Apps tab.
- **Launch time measured**: program names are on screen about 0.27 s after launch on a 2016 laptop
  (i7-6700HQ), with icons in the same frame once they are cached.
- The Ctrl and K keys in the title-bar search field are drawn as proper keycaps.
- The window toolkit was updated to its latest version.

## Known limits
- Alpha: the new window has not been run through the VM end-to-end tests yet; real uninstalls, moves and
  restores from it have only been tested against a simulated administrator part. Everything Purge
  removes still goes to quarantine first and can be put back.
- Pre-release: Hub does not offer it. While it is installed, Hub reads its version (0.2.0.4) as newer
  than 0.1.9; to go back, uninstall it and install 0.1.9.
- At the highest backdrop strengths, text on the accent-tinted parts (the Bold rail and the band behind
  the page title) can read a little less clearly than the cap promises; fixed in the next alpha.
- With two Purge windows open, the one closed last writes its settings over the other's.
- Screen readers have not been tried with the new window yet.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
