# Purge 0.1.2 (alpha)

Alpha. Quarantined items can be deleted early, the Leftovers page reads registry entries in plain words, and
uninstalling MSI programs works better.

## Changes since 0.1.1
- Quarantine: "Delete now" deletes a cleanup's quarantined items, or single items, before their retention ends.
  Purge's security prompt names every item, asks separately for user data, and says that Undo can no longer
  restore them. Backups keep their own retention.
- Leftovers: registry entries are described in words ("Starts with Windows: Discord", "Your account › Startup
  apps") instead of raw paths. The exact path is still shown on hover and in the details pane.
- Programs: nothing is selected when the list opens or is sorted, ticked rows stay ticked, and Uninstall stays
  greyed out until you pick a program.
- MSI programs (7-Zip and similar) uninstall with admin rights and get Windows Installer's plain removal
  dialog; "Close these programs first" no longer lists ordinary Windows processes for them.
- A failed uninstaller is reported after about 10 seconds instead of 3 minutes.
- The first step of an uninstall says what it is doing (a snapshot of the PC, usually 10 to 20 seconds).

## Known limits
- Alpha: everything Purge removes goes to quarantine first and can be restored from History & undo, until
  its retention ends or you use Delete now.
- Deleting quarantined items one after another asks for administrator rights each time.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
- If you installed a test build that was not a GitHub release, install this release once by hand so Hub
  reads the right version.
