# Purge 0.1.3 (alpha)

## Changes since 0.1.2
- Quarantine: "Delete now…" for a whole cleanup can also delete its registry backups, if you tick "Also delete
  its registry backups (its registry changes can then no longer be undone)". Purge asks for them in a security
  prompt of their own.
- Leftovers: "Delete instead of keeping in quarantine". Purge still moves the items to quarantine first, then
  asks in a second security prompt whether to delete them for good. If you cancel it, they stay in quarantine.

## Known limits
- No going back to 0.1.2 or older once registry backups were deleted early: an older Purge reads that cleanup's
  record as damaged and then refuses every new cleanup ("store integrity") until 0.1.3 or newer is installed
  again. Nothing is lost by this; installing the newer version again makes everything work as before.
