# Purge 0.2.0-alpha.2 (pre-release)

Second pre-release of Purge's new window. Every page is now wired: you can uninstall, review and move
leftovers, undo from History and manage Quarantine from the new window. The engine, the administrator
part (broker) and the safety rules are the same as in 0.1.9.

## What's new since alpha.1
- **Uninstall:** the full flow, from the confirmation to the leftovers. The confirmation shows the whole
  command that will run, and switching "quiet" off now shows the interactive command (0.1.x showed the
  quiet one either way). Several programs queue one after another; retry, forced cleanup and start over
  are there when an uninstaller fails.
- **Before the first Windows prompt** of a run, Purge explains what the administrator part will do;
  "Not now" cancels without a prompt.
- **Leftovers:** groups, evidence, Move to quarantine, results, and Put back all.
- **History & undo:** past cleanups on a timeline, put back some or all items, and recover an
  interrupted cleanup (resume or roll back).
- **Quarantine:** what is kept per drive, days left per cleanup, put back, delete now (optionally with
  the registry backups) and review what has expired.
- **If one page holds unfinished work** with the administrator part (a leftovers review, say), another
  page asks before ending it.
- **New look by default:** Bold, Violet and the Acrylic backdrop. Window backdrop is a new setting
  (Off, Mica, Acrylic). Existing settings from alpha.1 are kept.
- **New app icon.**
- **Smoother page transitions:** "Scale" and "Crossfade with depth" no longer stutter, and every page
  slides in from the same side.

## Known limits
- Alpha: the new window has not been run through the VM end-to-end tests yet. Real uninstalls, moves and
  restores from it have only been tested with a simulated administrator part. Everything Purge removes
  still goes to quarantine first and can be put back.
- Pre-release: Hub does not offer it. While it is installed, Hub reads its version (0.2.0.2) as newer
  than 0.1.9; to go back, uninstall it and install 0.1.9.
- Screen readers have not been tried with the new window yet.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
