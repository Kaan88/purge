# Purge 0.2.0-alpha.3 (pre-release)

Third pre-release of Purge's new window: smoother and sturdier. The engine, the administrator part
(broker) and the safety rules are the same as in 0.1.9.

## What's new since alpha.2
- **Page transitions run at your display's refresh rate** on every page (100 fps on a 100 Hz screen;
  before, 50–80 fps). While a page slides in, it is shown from a snapshot instead of being redrawn every
  frame, and the window paints less on idle frames too.
- **The "removed outside Purge" list acts on the program you clicked**, even if the list changed just
  before the click ("Dismiss" cannot be undone, so this mattered). The same applies to bars and to
  leftover groups.
- **When the administrator part ends during a leftovers review** (another page took it, or it closed),
  the Leftovers page says so and offers the way back, instead of leaving a Move button that cannot work.
- **"Try the held items again"** starts a new administrator part when the old one has ended, instead of
  reporting that it cannot tell what was moved.
- **"End it"**, the button that ends another page's unfinished work, cannot be hit by a stray
  double-click right after it appears.
- **If the engine fails to start**, History and Quarantine stay empty with the engine's message instead
  of showing sample data.
- The confirmation's Uninstall button stays off when Purge does not know the command that would run.

## Known limits
- Alpha: the new window has not been run through the VM end-to-end tests yet; real uninstalls, moves and
  restores from it have only been tested against a simulated administrator part. Everything Purge
  removes still goes to quarantine first and can be put back.
- Pre-release: Hub does not offer it. While it is installed, Hub reads its version (0.2.0.3) as newer
  than 0.1.9; to go back, uninstall it and install 0.1.9.
- Screen readers have not been tried with the new window yet.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
