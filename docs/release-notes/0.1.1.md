# Purge 0.1.1 (alpha)

Alpha. Pages that change things now wait for each other, and Purge installs and updates cleanly through Hub.

## Changes since 0.1.0
- Uninstall, the leftovers check for removed programs and the Leftovers page no longer run at the same time;
  each waits for the other and says why.
- A finished uninstall's leftover scan is kept (for up to 10 minutes) when the Leftovers page is still busy,
  with a "Show leftovers" button, instead of being replaced or lost.
- Administrator prompts and messages use the same plain wording on every page.
- Every Purge program carries its version, so Hub sees the installed version correctly.
- Silent setup (as Hub runs it) stops Purge's background helpers itself, writes a setup log, and reports a
  failure with an exit code instead of claiming success.

## Known limits
- Alpha: everything Purge removes goes to quarantine first and can be restored from History & undo.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
- If you installed a test build that was not a GitHub release, install this release once by hand so Hub
  reads the right version.
