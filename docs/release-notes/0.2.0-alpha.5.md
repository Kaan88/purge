# Purge 0.2.0-alpha.5 (pre-release)

Fifth pre-release of Purge's new window. The engine, the administrator part (broker) and the safety rules
are the same as in 0.1.9.

## What's new since alpha.4
- **The Programs search field works like a real text field**: drag to select (it scrolls when you reach
  the edge), double-click a word, triple-click for all, and a right-click or Shift+F10 menu with Cut, Copy,
  Paste and Select all. The command palette (Ctrl+K) got the same menu.
- **A press or drag never stays stuck.** If the window loses focus mid-drag (Alt+Tab, a dialog), or the page
  changes while you hold the list's scroll bar or the backdrop slider, Purge lets go instead of carrying
  on with the next mouse move.
- **Text stays readable over the backdrop in Bold too.** The strength cap now also covers the tinted rail
  and the band behind the page title. In Bold at full strength a little less of the desktop shows through
  than in alpha.4, and in exchange text keeps its contrast.
- **Two Purge windows no longer overwrite each other's settings** or window place, and a damaged or
  unreadable settings file is left alone (or repaired) instead of being written over.
- Cross-fades no longer make the backdrop jump halfway through.
- The window toolkit was updated to its latest version.
- Behind the scenes: the VM end-to-end tests can now drive this new window, which is the step toward beta.

## Known limits
- Alpha: the new window has not yet passed the VM end-to-end test (real uninstall, move and restore from it);
  that run is next. Everything Purge removes still goes to quarantine first and can be put back.
- Pre-release: Hub does not offer it. While it is installed, Hub reads its version (0.2.0.5) as newer than
  0.1.9; to go back, uninstall it and install 0.1.9.
- Secondary (grey) text over the backdrop is kept at 3:1 contrast, not 4.5:1: at 4.5:1 almost no backdrop
  could show in dark mode.
- Screen readers have not been tried with the new window yet.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
