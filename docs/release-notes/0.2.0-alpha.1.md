# Purge 0.2.0-alpha.1 (pre-release)

First pre-release of Purge's new window, rewritten in Rust on a new UI toolkit. It replaces the WinUI
app of 0.1.x; the engine, the broker and the safety rules are unchanged. This build is for looking at
the new window: only the Programs page is wired to the real engine, and nothing can be uninstalled
from it yet. Use 0.1.9 to uninstall.

## What works
- Programs: the real list from the engine, with icons, sizes and install dates; the Apps, Components,
  Unnamed and Recent tabs; search, sort and multi-select; the details pane (installer type, location,
  size, commands, registry key); the "removed outside Purge" group; open folder, web search and refresh.
- Looks: Standard and Bold, seven colour presets (or the Windows accent) in light and dark, eight page
  transitions, and high contrast with the system colours. All are in Settings, which are kept between runs.
- The window opens in well under a second and shows the program names in about a quarter of a second.

## Not available yet
These show as "Not available yet in this preview":
- Uninstalling (the Uninstall page), and the administrator part's consent flow.
- Leftovers: reviewing and moving what a program left behind, and undo.
- History & undo, and Quarantine.
- "Check for leftovers" on a program removed outside Purge.

## Changes since 0.1.9
- The window is new: Purge.exe is now a single Rust program (no Windows App SDK files next to it).
  Updating over 0.1.x removes the old app's files from the install folder.
- New Settings: look, colour preset, theme and page transition, with a live preview.

## Known limits
- Pre-release: Hub does not offer it (Hub only installs full releases); install it from this page. While
  it is installed, Hub reads its version (0.2.0.1) as newer than 0.1.9 and offers no 0.1.x update; to go
  back, uninstall it and install 0.1.9.
- Not yet tested in the VM end-to-end, and screen readers have not been tried with the new window.
- The setup is not code-signed yet, so SmartScreen warns: More info, then Run anyway.
- Purge only knows what a program left if it saw that program while it was installed.
