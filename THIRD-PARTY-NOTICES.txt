Third-party notices for Purge
==============================================================================

Purge itself is under the MIT licence (LICENSE); NOTICE holds the notices of
the code it ports. This file lists the other software that purge-engine.exe,
purge-broker.exe, Purge.exe contain: (1) the Rust standard library, which
every Rust program links statically, with the 9 crates of the toolchain that
it links (rustc 1.99.1 (58cf8f9c3 2026-10-13)); (2) the 136 third-party Rust
crates of Cargo.lock that the exes depend on.

Not listed here: the Microsoft C runtime, which the exes link statically
(crt-static) as Microsoft's redistributable runtime under Microsoft's own
terms, and the Windows system libraries they call.

Each entry names a licence and the licence texts that come with it; the texts
follow the lists, each given once. They are reproduced as their packages ship
them, with line endings, trailing whitespace and leading and trailing blank
lines normalised. Where a licence offers a choice ("OR"), the texts of every
choice are reproduced. Both lists may name a little more than is linked: the
crates come from the workspace's resolve with its features unified, and the
standard library's crates are every version the toolchain names of each crate
it ships for the target.

Generated from Cargo.lock and the pinned toolchain by `cargo xtask notices`
(tools/xtask/src/notices.rs) for the target x86_64-pc-windows-msvc; do not
edit by hand. `cargo xtask notices --check` fails when this file is out of
date.
